② تشغيل Claude Code — Cheatsheet

# بدء العمل من جذر المشروع (يقرأ CLAUDE.md تلقائياً)
cd C:\SchoolApp && claude
# أول رسالة في كل جلسة:
/init
# عمل معزول على مشروع واحد فقط:
claude --worktree teacher
# نشر مشروع (نفس Deployment ID):
cd master-admin && clasp push      # ثم: Manage deployments → Edit → New version
# تراجع طارئ:
clasp deploy -i [DEP_ID] --versionNumber [LAST_GOOD]
# تحقق الصحة:  افتح  ?action=health
  • /init ≠ --worktree: الأول يُحمّل السياق (CLAUDE.md)، الثاني يعزل نسخة Git. استخدم /init دائماً، و--worktree عند العزل فقط.
  • الربط الأمثل: الكمبيوتر المحلي + GitHub معاً (clasp يرفع لـGAS، وGit نسخة احتياطية). لا تعتمد على واحد.
  • Cowork للتحليل/التوثيق · Claude Code للتعديل/النشر. لا تفتح الاثنين على نفس الملف بالوقت نفسه.
