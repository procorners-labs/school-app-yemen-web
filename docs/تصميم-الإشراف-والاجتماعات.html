① الأساس الحالي (نبني عليه — لا نظام منفصل)

القواعد المتاحة فعلاً: تعيين مهمة لمعلم (addTaskProtected) · قائمة بفلاتر (getTasksProtected) · تأكيد المشرف وتغيير الحالة + العمود 13 (updateTaskStatusProtected) · إنجاز تلقائي عند انتهاء الوقت · صلاحيات عبر _tcCanManageTasks. سنعيد استخدام هذا كلّه — بلا أعمدة جديدة (نستخدم بادئة id وtype وnotes للتمييز، تفادياً لأي هجرة بيانات).

② الاجتماع الذكي (كل المعلمين + حضور بالاستثناء)

  1. التعيين لكل المعلمين: عند اختيار «كل المعلمين» (متاح لدور الوكيل/المدير فقط)، تُنشأ صفّ مهمة لكل معلّم نشط بنفس type='اجتماع' وdate/time/description، وبمعرّف مجموعة موحّد: id = 'MTG'+ts+'_'+idx (يربط صفوف الاجتماع الواحد).
  2. الحضور الافتراضي: حالة كل الصفوف عند الإنشاء = «حاضر» تلقائياً.
  3. تسجيل الغياب بالاستثناء: واجهة المشرف تعرض قائمة معلمي الاجتماع؛ يؤشّر فقط على الغائبين → تتحوّل صفوفهم إلى «غائب» عبر updateTaskStatusProtected؛ الباقي يبقى «حاضر» آلياً.
  4. التأكيد: زر «تأكيد الاجتماع» يضبط الحالة النهائية ويسجّل المؤكِّد (العمود 13)، ثم يُؤرشَف (القسم ④).

دالة جديدة مقترحة addMeetingForAllProtected(params) تلفّ المعلمين النشطين وتُنشئ الصفوف بمعرّف المجموعة — تعيد استخدام منطق addTaskProtected.

③ الإشراف الأسبوعي المتكرّر (نفس الملف، تبويب صغير)

قالب التكرار يُحفظ في تبويب واحد صغير داخل نفس ملف المعلم: «الإشراف_الأسبوعي» — يُدار من نفس الصفحة، والمهام المتولّدة تُكتب في ورقة المهام نفسها.

المولّد (Trigger يومي)

دالة generateDailySupervision() تعمل يومياً: تقرأ صفوف «اليوم» (يوم الأسبوع) من تبويب الإشراف، وتُنشئ في ورقة المهام صفّاً لكل معلّم بـtype='إشراف' وid='SUP'+date+'_'+teacher وtime محسوباً:
  • طابور الصباح ← وقت «بداية الدوام» (إعداد ثابت محفوظ ومعروض في الويب).
  • إشراف الراحة ← من إعداد الجدول «☕ استراحة كل صف (بعد الحصة رقم)» + تواقيت الحصص (لكل صف وقته، لا توقيت موحّد).
منع التكرار: قبل الإنشاء يتحقّق أنّ id='SUP'+date+'_'+teacher غير موجود (idempotent).

المهام التلقائية للمعلمين فقط (لا طلوع/نزول طلاب على المعلمين). كل صف/شعبة في وقت راحته الخاص فقط.

④ التأكيد والأرشفة (إعادة استخدام الحالة)

  • تأكيد الإنجاز: المشرف/الوكيل يضغط «تأكيد» → updateTaskStatusProtected يضبط الحالة إلى «مؤكَّد» ويسجّل المؤكِّد (العمود 13).
  • الأرشفة بلا نقل بيانات: «النشطة» = حالات (مكلّف/قيد التنفيذ/حاضر بانتظار التأكيد)؛ «الأرشيف» = (مؤكَّد/منفّذ/غائب/منتهٍ). فلترة بالحالة فقط — نفس الورقة، نفس الصفحة، تبويبان في الواجهة.
  • الإشراف الأسبوعي يمرّ بنفس الدورة: تولّد → تأكيد → أرشيف.

⑤ الصفحة (frontend/teacher — إدارة المهام والإشراف)

أربعة تبويبات داخل نفس الصفحة: تعيين مهمة (مع خيار «كل المعلمين») · المهام النشطة · الإشراف الأسبوعي (إدارة القالب) · الأرشيف. تحسينات الواجهة: استبدال «(اختياري)» بأيقونات، نوافذ منبثقة احترافية ديناميكية، خيارات بحسب نوع المهمة (اجتماع/إشراف/عامة).
