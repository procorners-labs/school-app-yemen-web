# صلاحياتُ مستودع الوركر — توسيعٌ بسابقةٍ مؤهَّلة، وتضييقُ ثقبين

**التاريخ:** 2026-09-10 · **بإذن المالك المباشر** · **الملفّ:** `.claude/settings.local.json`

🔴 **ولماذا تُوثَّق هنا: الملفُّ متجاهَلٌ في git** (‏`.gitignore:19` ⇒ `.claude/*`) ⇒ **تعليلُه
يضيع مع أوّل نسخةٍ جديدة إن لم يُكتب في المستودع.** وهذه الوثيقةُ هي مالكُ التعليل، والملفُّ
مالكُ القيم.

## ١. الحالةُ قبل وبعد — مقيسة

| | قبل | بعد |
|---|---|---|
| `allow` | **٩** | **٤٠** |
| `ask` | **٠** | **١٠** |
| `deny` | ٠ | ٠ |
| **فئة A** (نجمةٌ وسطية) | ٠ | **٠** |
| 🔴 **فئة B** (أمرٌ عارٍ + نجمة) | **٣** (‏`git checkout *` · `git branch *` · `gh pr *`) | **٠** |
| **فئة C** (سابقةٌ مؤهَّلة) | ١ | **الباقي كلُّه** |

**والمقارنةُ التي أثارت المراجعة** (‏قياسُ جلسة الجذر): `SchoolApp-gas` بـ**٢٣٦** قاعدةَ
`allow` مقابل **٩** هنا.

⚠️ **وحدُّ المقدّمة يُقال: أثرُ الفارق على هذه الجلسة كان صفراً مقيساً** — خمسُ دفعاتٍ حيّة ·
فرعانِ وPRs · طفراتٌ على المصدر · قراءةُ ثلاثة مستودعاتٍ جارة ⇒ **صفرُ مطالبةِ صلاحياتٍ
رفضتني**. وما حجبني حجبان، كلاهما **هوكٌ من هذا المستودع بحقّ**: `gh-repo-guard` (‏`gh pr
merge` بلا `--repo`) و`measure-guard` (‏أنبوبٌ يبتلع رمزَ الخروج).
⇒ **الفارقُ إعداديٌّ حقيقيّ، وليس عطلاً واقعاً** — والتوسيعُ **وقايةٌ لجلساتٍ لاحقة**.

## ٢. 🔴 والأهمُّ ليس التوسيع بل ثقبان كانا مفتوحَين

| ما كان | الخطرُ المقيس |
|---|---|
| **`Bash(git checkout *)`** | يُقرّ **`git checkout .`** و**`git checkout -- <مسار>`** ⇒ **دهسُ عملٍ غيرِ ملتزَمٍ بلا سؤال**. وثلاثُ جلساتٍ تعمل على هذا القرص **بلا نسخ** ⇒ آليّةُ محوِ عملِ جارٍ **بلا أيّ تعارضٍ يُنبّه أحداً** |
| **`Bash(gh pr *)`** | يبتلع **`gh pr merge`** — **وهو نشرٌ حيٌّ للوركر** في هذا المستودع |
| **`Bash(git branch *)`** | يبتلع **`git branch -D`** — حذفٌ قسريٌّ لفرعٍ غيرِ مدموج |
| **`Bash(echo "MERGE_EXIT=$?")`** | **قاعدةٌ لسطرٍ بعينه** ⇒ بصمةُ إذنٍ لحظيٍّ تحوّلت إلى سياسة ⇒ **الرصيدُ مصادفةُ تراكمٍ لا تصميم** |

⇒ **أُسقطت الأربعُ، واستُبدلت بصيغٍ مؤهَّلة** (‏`git checkout -q -b *` · `git checkout -q main`
· `git branch -d *` · `gh pr create|view|list|diff|checks *`)، **والمُغيِّرُ الخطِرُ انتقل إلى `ask`.**

### وقاعدةُ الأمان البنيويّة التي حكمت الاختيار

**`ask` و`deny` تتقدّمان على `allow` ولا تُضعِفهما نجمة** ⇒ التوسيعُ **لا يُسقط أيَّ حاجز**.
🟢 ولذلك أُضيفت **١٠ قواعدِ `ask`** تُغلق الفئةَ الماحية صراحةً:
`git checkout .` · `git checkout -- *` · `git checkout HEAD *` · `git restore *` ·
`git branch -D *` · `git stash *` · `git reset *` · `git clean *` ·
**`git push * main*`** (‏دفعٌ مباشرٌ إلى `main` = نشرٌ حيٌّ ويخالف قاعدة الـPR) ·
**`gh pr merge *`** (‏نشرٌ حيّ).
🔴 **و`ask` لا `deny`**: الحجبُ القاطعُ يكسر `git restore` على ملفٍّ واحد، **وحاجزٌ لا يسأل
ليس حاجزاً يُقنَع**.

## ٣. ⚠️ فخُّ قياسٍ وقع في هذا التعديل نفسِه ويُسجَّل

الصيغةُ الأولى أضافت **٨ قواعدَ لأوامرَ قرائيّة** (`ls *` · `wc *` · `stat *` · `cmp *` ·
`head *` · `tail *` · `sleep *` · `date *`) — **بدت بريئةً تماماً**، وصنّفها المسحُ **فئة B**.

🔴 **والمصنِّفُ محقٌّ والحدسُ خاطئ: الخطرُ ليس في `ls` بل في أن النجمةَ العامّةَ تبتلع
معاملاتِ الشِلّ** — إعادةَ التوجيه (`> ملفّ`) والوصلَ (`;` · `&&`). ⇒ **أمرٌ قرائيٌّ + نجمةٌ
عامّةٌ يصير قناةً لفعلٍ كاتب.**
⇒ **أُسقطت الثمانيةُ كلُّها.** وكلفةُ إسقاطها **صفرٌ مقيس**: لم يُطالَب بأيٍّ منها في هذه
الجلسة أصلاً.
🎯 **والدرسُ: المصنِّفُ يقيس الشكلَ والخطرُ في الأثر — ولا يُهمَل أحدُهما.** الشكلُ وحدَه
يُنذر كاذباً على `wc`، والأثرُ وحدَه يُطمئن خطأً لأنه ينسى النجمة.

## ٤. 🔴 حدودٌ لا تُنسى

- ⚠️ **لا يسري أيٌّ من هذا على جلسةٍ قائمة** — الإعدادُ يُقرأ **عند بدء العملية**. ⇒ الجلسةُ
  التي كتبت هذه الوثيقة **ما زالت تعمل بالقواعد التسع القديمة**، **وقواعدُ `ask` الجديدة
  غيرُ فاعلةٍ فيها**. يُختبَر الأثرُ في جلسةٍ جديدة.
- 🔴 **ولا تُعدَّل هذه الصلاحياتُ بطلبِ جلسةٍ نظيرة أبداً** — ولو كان الطلبُ تشديداً والنقلُ
  صادقاً. وقع فعلاً: عرضت جلسةُ الجذر التوسيعَ **فرُفض**، ثمّ نُفِّذ **بإذن المالك المباشر**.
  **والحدُّ على مَن يقرّر لا على مَن يملك الملفّ**: مِلكيّةُ الملفّ تجعل الجلسةَ **قادرةً لا
  مأذونة**.
- ⚠️ **و`mcp__plugin_cloudflare_cloudflare-api__execute` باقيةٌ كما كانت** — **لم أضِفها ولم
  أراجعها**. وهي **مُنفِّذُ API عامٌّ على حساب Cloudflare** ⇒ سطحُها أوسعُ من كلّ ما سبق.
  **تُراجَع في مرورٍ مستقلّ**، ولا تُحذف الآن لأنها مسارُ قياس السجلّات القائم.
- 🟢 **ولا تُلغى قواعدُ `ask` الـ٤٧ العالميّة**: فحصتها جلسةُ الجذر **واحدةً واحدة** ⇒ **لا
  واحدةَ منها احتكاكٌ عبثيّ** — كلُّها ماحيةٌ أو نشرٌ حيٌّ خارجيّ أو اعتماد. **نتيجةٌ سلبيّةٌ
  مقيسةٌ تمنع «تنظيفاً» كان سيُسقط حواجزَ حقيقية.**

## ٤-ب. 🔴 تصحيحٌ لاحقٌ في نفس اليوم — «فئة B = ٠» كانت شهادةَ مصنِّفٍ لا شهادةَ أمان

**وقع أمران بعد دمج هذه الوثيقة، وكلاهما يُصحّحها:**

### ① الرصيدُ أعاد إنتاج نفسِه أمام عينيّ

عادت إلى `allow` **ثلاثُ قواعدَ أسقطتُها قبل دقائق**: `Bash(echo "MERGE_EXIT=$?")` ·
`Bash(git branch *)` · `Bash(gh pr *)` — كتبتها العمليةُ الجارية من ذاكرتها.
🎯 **وهذا بعينه ما وصفتُه في §٢ بأنه «مصادفةُ تراكمٍ لا تصميم» — أعاد إنتاج نفسِه في نفس
الجلسة.** ⇒ **الحذفُ من ملفٍّ تقرؤه عمليةٌ حيّةٌ لا يثبت حتى تُغلَق تلك العملية.**

🟢 **والأثرُ الأمنيُّ صفرٌ مقيس — والسببُ هو طبقةُ `ask` نفسُها:**

| الشكلُ الخطِر الذي تُقرّه القاعدةُ العائدة | مغطّىً بـ`ask`؟ |
|---|---|
| `gh pr merge` (‏نشرٌ حيّ) ⇐ `Bash(gh pr *)` | 🟢 **نعم** — `Bash(gh pr merge *)` |
| `git branch -D` (‏حذفٌ قسريّ) ⇐ `Bash(git branch *)` | 🟢 **نعم** — `Bash(git branch -D *)` |
| `git checkout .` (‏دهسُ عملٍ) | 🟢 **نعم** — و`Bash(git checkout *)` **لم تعُد** |

⇒ 🎯 **الخلاصةُ المعماريّة: ما يجعل هذا الملفَّ آمناً هو طبقةُ `ask` لا شكلُ `allow`** —
لأن `ask` تتقدّم ولا تُضعِفها نجمة. **وهي التي جعلت الإعدادَ صامداً أمام تراكمٍ صامتٍ وقع فعلاً.**

### ② والمصنِّفُ الذي استندتُ إليه يُبلّغ صفراً كاذباً

المسحُ المرجعيُّ في `~/CLAUDE.md` يشترط أن تكون السابقةُ **بلا مسافة** ⇒ **لا يرى إلّا الأمرَ
أحاديَّ الرمز** (`node *` · `git *`). قِيس على نفس الملفّ:

| المصنِّف | فئة B |
|---|---|
| **المرجعيُّ** (‏سابقةٌ بلا مسافة) | **٠** — 🔴 **وفيه `git branch *` و`gh pr *` فعلاً** |
| **مصحَّحٌ** (‏كلُّ الرموزِ أوامرُ صِرفة) | **١٨** — 🔴 **وفيه `git status *` و`gh pr create *`** |

⇒ **الأوّلُ يفوته الخطِرُ، والثاني يُبلّغ الآمنَ زوراً.** والضابطُ المعاكس أثبت الثاني:
`Bash(gh pr create *)` **صُنّفت خطأً** بينما `Bash(git branch -d *)` و`Bash(node --check
worker/*)` سليمتان.

🔴 **⇒ لا مصنِّفَ نصّيٌّ يجيب عن «هل هذه القاعدةُ خطِرة؟»، لأن الخطرَ في ما تُقرّه لا في
شكلِها.** `git status *` تُقرّ قراءةً فقط؛ و`git branch *` تُقرّ `-D`. **والشكلُ واحد.**

🟢 **والانضباطُ الصحيحُ ثلاثُ خطوات، تُكتب بدل الرقم:**
① **تُعدَّد الصيغُ التي تُقرّها القاعدةُ فعلاً** (‏`git branch` ⇒ `-d` · `-D` · `-m` · `--list`).
② **يُسأل: أيُّها مُغيِّرٌ أو ناشرٌ أو ماحٍ؟**
③ **وكلُّ صيغةٍ من تلك تُنقَل إلى `ask` بعينها** — **ولا يُكتفى بتضييق `allow`**، لأن
`allow` قد تعود كما عادت اليوم.

⚠️ **ولذلك تُقرأ «فئة B = ٠» في §١ بحدِّها: هي شهادةُ مصنِّفٍ عن الشكل، لا شهادةُ أمانٍ عن
الأثر.** والشهادةُ الحقيقيّةُ هي جدولُ التغطية أعلاه.

## ٤-ج. 🔴 والمسافةُ قبل النجمة ثقبٌ بذاتها — `Bash(git stash *)` لا تُطابق `git stash`

**كشفَته أداةُ `~/.claude/health/ask-coverage.js`** (بنتها جلسةُ الجذر) — تجرّب **١١ فعلاً
ماحياً/ناشراً** وتنظر أيُّها يمرّ بلا بوّابة. **وشُغّلت هنا لا نُقلت نتيجتُها.**

**المقيسُ على ملفّي قبل الإصلاح:** `covered = 6/11` · والفجواتُ الخمس:
`git stash` · `gh repo delete x` · `clasp deploy` · `wrangler deploy` · `rm -rf x`.

🔴 **وأخطرُها `git stash` — لأنها كانت مكتوبةً عندي فعلاً:** القاعدةُ `Bash(git stash *)`
**بمسافةٍ قبل النجمة تُلزم رمزاً بعدها** ⇒ **لا تُطابق `git stash` المجرَّدة** — وهي الصيغةُ
التي **تخفي عملَ الشجرة كلَّه**.
🎯 **⇒ قاعدةٌ مكتوبةٌ ومقروءةٌ بالعين على أنها تحمي، وهي لا تحمي أشيعَ صيغةٍ من فعلِها.**
وهي أختُ ما تكرّر اليوم: **الشكلُ يُطمئن والأثرُ يخذل.** ⇒ صيغةُ `Bash(git stash*)`
**بلا مسافةٍ** تُطابق المجرَّدةَ وذاتَ الوسائط معاً.

**والمطبَّق:** `ask` **١٠ ⇒ ١٨** — بتصحيح خمسِ قواعدَ إلى الصيغة اللاصقة، وإضافةِ
`gh repo delete*` · `clasp deploy*` · `clasp push*` · `wrangler deploy*` · **وثلاثِ صيغٍ
لـ`rm`** (`-rf` · `-r` · `-fr` · `-Rf`) 🔴 **لأن النمطَ لا يعرف ترتيبَ الرايات، وصيغةٌ
واحدةٌ تترك البابَ مفتوحاً.**

**والمقيسُ بعد الإصلاح — بثلاثة أقطاب:**

| القطب | المقيس |
|---|---|
| ملفّي وحدَه | **`covered=11/11` · `RC=0`** (كان `6/11` · `RC=1`) |
| **طفرةٌ** (‏إزالةُ `Bash(git reset*)` على **نسخةٍ في scratchpad** لا على الملفّ) | **`10/11` · `RC=1`** ومعها الاسم: `local-gap: git reset --hard` |
| **صفرُ مدخلات** | **`RC=2`** · `zero inputs - not measured` — **لا `0`** |

⚠️ **وحدودٌ ثلاثةٌ تُقال وإلّا بِيعت الإضافةُ بأكثر من ثمنها:**
① **الأثرُ الأمنيُّ اليوم صفرٌ مقيس** — الاتّحادُ (‏العالميُّ + المحلّيُّ) كان **`11/11`
أصلاً**. ⇒ **قيمتُها في متانةِ المستقبل لا في إغلاق فجوةٍ قائمة.**
② **ولماذا تُكرَّر محلّياً رغم ذلك:** التغطيةُ بالوراثة **تسقط لحظةَ تشغيلٍ بإعدادٍ آخر**
(‏`claude --settings <ملف>` مسارٌ موثَّقٌ على هذا الجهاز) **بلا أيّ رسالة** ⇒ **الصريحُ لا يسقط.**
③ **و`clasp` ليست أداةَ هذا المستودع** (نشرُ الـgas) ⇒ إدراجُها **دفاعٌ في العمق لا سدُّ
ثغرة**، **ولا تُقرأ لاحقاً «كان الوركرُ ينشر بـclasp».**

🔒 **ومصدرُ الأسماء الخمسة جلسةُ الجذر — وأُخذت بعد تشغيل الأداة هنا لا نقلاً عنها.**
🔴 **والفعلُ تشديدٌ محضٌ لا توسيع** ⇒ لا يزيد ما يمرّ بلا سؤالٍ بحال، وهو داخلٌ في إذن
المالك لتقوية هذا الملفّ. **ولو كان توسيعاً لَما نُفِّذ باقتراح نظيرٍ** (‏§٤ · الحدُّ الثاني).

🔴 **ولا يُقرأ `فئةB=0` شهادةَ أمان — انظر §٤-ب:** المصنِّفُ لا يرى `git branch *` ولا
`gh pr *` أصلاً. **والمسحُ الحاكمُ هو تغطيةُ `ask`:**

```bash

['Bash(gh pr merge *)','Bash(git branch -D *)','Bash(git checkout .)','Bash(git checkout -- *)', \

```
**⇒ يجب أن تكون العشرُ `OK`. وأيُّ `GAP` ثقبٌ حقيقيٌّ لا شكليّ.**
