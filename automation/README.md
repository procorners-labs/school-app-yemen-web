# دليل أتمتة المنشورات — Claude + Google Sheets + Apps Script + Canva

عُدّة جاهزة تربط بياناتك وتولّد منشورات المدرسة **آلياً وبشكل صحيح ومتوافق**:
أنت تكتب فكرة بسيطة في جدول → **Claude** يكتب النص → **Canva** يصمّم الصورة →
أنت تراجع وتعتمد → النشر التلقائي على **فيسبوك وإنستغرام**.

> اخترتَ: **مراجعة ثم نشر** (الأأمن) + تشغيل مجاني عبر **Google Apps Script**.
> لا يُنشر أي شيء قبل أن تعتمده بنفسك.

---

## ١) كيف يعمل النظام (الصورة الكاملة)

```
   ┌── ورقة «المنشورات» في Google Sheets (مركز التحكم) ──┐
   │  تكتب: النوع + فكرة بسيطة + المنصات + الحالة=جديد   │
   └───────────────────────────┬─────────────────────────┘
                               ▼
        ② توليد المسودّات (تلقائي / بضغطة زر)
        ├─ Claude API  → يكتب نصاً عربياً راقياً + وسوم + إيموجي
        └─ Canva API   → يملأ قالبك ويُصدّر صورة جاهزة
                               ▼
                   الحالة تصير «للمراجعة»
                               ▼
            👁️ أنت تراجع النص والصورة في الجدول
              وتغيّر الحالة يدوياً إلى «معتمد»
                               ▼
        ③ نشر المعتمد (تلقائي / بضغطة زر)
        └─ Meta Graph API → فيسبوك + إنستغرام
                               ▼
                   الحالة تصير «منشور» ✅
```

**ثلاثة أنواع محتوى مدعومة** (كما طلبت): `إعلان` (أخبار/فعاليات) ·
`تهنئة` (إنجازات الطلاب) · `تحفيزي` (محتوى يومي ملهم).

## ٣) خطوات الإعداد بالترتيب

### أ) إنشاء الجدول وإلصاق الكود
1. أنشئ Google Sheet جديداً باسم «منشورات المدرسة».
2. من القائمة: **Extensions ▸ Apps Script**.
3. انسخ محتوى ملفات هذا المجلّد الستة إلى المشروع (ملف لكل واحد):
   `Config.gs` · `Setup.gs` · `ContentAI.gs` · `CanvaDesign.gs` · `Publisher.gs` · `Pipeline.gs`.
4. احفظ، ثم **أعِد تحميل الجدول** — ستظهر قائمة جديدة اسمها **«أتمتة المنشورات»**.
5. من القائمة اختر **① تجهيز الجدول** — يُنشئ الأعمدة والقوائم والتنسيق تلقائياً.

### ب) إضافة المفاتيح السرية (Script Properties)
في محرّر Apps Script: **⚙️ Project Settings ▸ Script Properties ▸ Add property**.
أضِف ما يلزمك:

| المفتاح (Property) | القيمة | إلزامي |
|---|---|---|
| `CLAUDE_API_KEY` | مفتاحك من console.anthropic.com | ✅ |
| `CLAUDE_MODEL` | `claude-opus-4-8` (الافتراضي إن تركته) | — |
| `FB_PAGE_ID` | معرّف صفحة فيسبوك | للنشر على فيسبوك |
| `FB_PAGE_TOKEN` | توكن صفحة فيسبوك **طويل الأمد** | للنشر على فيسبوك/إنستغرام |
| `IG_USER_ID` | معرّف حساب إنستغرام Business المربوط بالصفحة | للنشر على إنستغرام |
| `CANVA_TOKEN` | توكن Canva Connect | اختياري (للتصميم الآلي) |
| `CANVA_BRAND_TEMPLATE_ID` | معرّف قالب Canva | اختياري |

> 🔒 **لا تكتب أي مفتاح داخل الكود.** كلها في Script Properties فقط.

### ج) الحصول على المفاتيح
- **Claude:** سجّل في `console.anthropic.com` ▸ API Keys ▸ Create Key.
- **فيسبوك/إنستغرام:** عبر **Meta for Developers** (developers.facebook.com):
  أنشئ تطبيقاً، اربط صفحتك، واحصل على *Page Access Token* بصلاحيات
  `pages_manage_posts` و`instagram_content_publish` و`pages_read_engagement`،
  ثم حوّله إلى **توكن طويل الأمد**. اربط حساب إنستغرام Business بالصفحة.
- **Canva:** عبر `canva.com/developers` (Connect API) — أنشئ Brand Template
  فيه حقلان نصيان باسمي `title` و`body` (يطابقان الكود).

## ٤) كيف تستخدمه يومياً

1. في ورقة **«المنشورات»**، أضِف صفاً:
   - **النوع:** إعلان / تهنئة / تحفيزي
   - **المدخلات:** فكرة بسيطة، مثال: «تهنئة الطالب أحمد بالمركز الأول في مسابقة الرياضيات»
   - **المنصات:** `فيسبوك، إنستغرام`
   - **تاريخ النشر:** (اختياري — لجدولة لاحقة)
   - **الحالة:** اتركها `جديد`
2. اختر **② توليد المسودّات** → يملأ النص والصورة، وتصير الحالة `للمراجعة`.
3. راجِع النص والصورة. عدّل إن شئت، ثم غيّر الحالة يدوياً إلى `معتمد`.
4. اختر **③ نشر المعتمد** → يُنشر ويصبح `منشور`.

### التشغيل التلقائي الكامل
من القائمة: **تفعيل التشغيل التلقائي (كل ساعة)**.
عندها يعمل النظام وحده كل ساعة: يولّد مسودّات الصفوف `جديد`،
ويَنشر الصفوف `معتمد` التي حان وقتها — وتبقى أنت بوّابة الاعتماد.

## ٥) حالات المنشور (عمود «الحالة»)

| الحالة | المعنى | من يضبطها |
|---|---|---|
| `جديد` | جاهز للتوليد | أنت |
| `قيد التوليد` | يعمل Claude/Canva الآن | النظام |
| `للمراجعة` | جاهز — راجِعه | النظام |
| `معتمد` | مأذون بالنشر | **أنت** |
| `منشور` | تم النشر ✅ | النظام |
| `فشل` | خطأ — اقرأ عمود «السجل» | النظام |

## ٦) أسئلة شائعة

- **لا أملك Canva؟** النظام يعمل: يولّد النص ويتركه `للمراجعة`،
  وتضع رابط صورة يدوياً في عمود «رابط الصورة» قبل الاعتماد.
- **إنستغرام يتطلّب صورة** برابط عام — لذا لا يُنشر عليه دون تصميم.
  فيسبوك ينشر نصاً فقط إن لم توجد صورة.
- **هل يخترع Claude معلومات؟** لا — التعليمات تمنعه من اختلاق أسماء/أرقام/تواريخ
  غير موجودة في مدخلاتك.
- **تغيير نبرة المحتوى أو الوسوم؟** عدّلها في ورقة «الإعدادات» دون لمس الكود.
- **اليمن وضعف الشبكة؟** كل المعالجة على خوادم Google (تعمل عادةً دون VPN)،
  ولا علاقة لها بحجب `github.io`.
